# Held-out graph-memory cohort provenance

All three narratives and their annotations are original synthetic works created
for this experiment before any extraction-quality results. No published text,
external story, user book, personal note or account data was used. Character,
place and object descriptions are invented and carry no biographical claim.

Narratives and annotations are dedicated under **CC0-1.0**. Shared export,
validation and test tools remain **Apache-2.0**. There are no external source
licences or attribution requirements.

The initial six cases and their frozen v1 export are not rewritten by this
cohort. This is a separately authored, preregistered diagnostic extension, not a
post-result edit to make an arm succeed or fail. Human review of the gold is
still required; mechanical span consistency is not semantic endorsement.
