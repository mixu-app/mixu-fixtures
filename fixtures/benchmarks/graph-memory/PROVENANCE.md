# Graph-memory benchmark provenance

All six stories, annotations and generated stress sentences are original synthetic
material authored for Mixu's graph-memory experiments. There is no external book,
article, dataset, user account or personal note as a narrative source.

The stories, annotations and stress exports are dedicated under **CC0-1.0**.
Generator, validation and test code use **Apache-2.0**. No third-party attribution
or source permission is needed. Synthetic character names are invented labels;
coincidental overlap with a real person conveys no biographical assertion.

Input files were authored separately from answer annotations. Span quotes point
to the exact authored text. Stress sentences are produced by deterministic
language templates; their relationship annotations are directly constructed from
the same explicit template slots, while independent tests check source spans,
chain continuity, horizons and counts. This establishes internal consistency,
not human-verified linguistic or benchmark validity.

The corpus is a small diagnostic set, not evidence of general reading accuracy,
model superiority, robust language comparison or resistance to arbitrary hostile
text. Six scenarios are assigned to two cases per language, so language and
scenario are confounded. Independent annotation review remains required before
using a run as an acceptance decision.
