| Path | Applies to | License |
|---|---|---|
| [`../LICENSE`](../LICENSE) | `fixtures/**`: story text and annotations | CC0-1.0 |
| [`Apache-2.0.txt`](Apache-2.0.txt) | `tools/`, `schema/`, `justfile`, CI workflow | Apache-2.0 |

The corpus is deliberately public-domain-dedicated: a fixture must be readable,
quotable and modifiable by any implementer, including a commercial one, or it
cannot serve as a shared regression base. Each fixture additionally records its
own `content_basis` and `rights_note`; a fixture whose basis is
`EXPLICITLY_LICENSED` keeps that third-party licence, which this file does not
override.
